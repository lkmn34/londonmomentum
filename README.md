# London Momentum – website

Companion website for the **@ldnmomentum** Instagram account: health & fitness tips, free health tools and online class booking for Londoners.

- `src/content.py` – all topics, articles, sources, classes and timetable (edit content here)
- `src/build.py` – generates the static HTML (`python3 src/build.py`)
- `content/wordpress-export.json` – the same content structured as WordPress categories/posts for the later WordPress move
- `assets/` – CSS, JS, fonts, images (from the Instagram designs) and Fluent emoji (MIT licence, Microsoft)

Hosted on GitHub Pages. Booking, newsletter and contact forms are previews (no data is sent anywhere).
